# CodeAlpha Full Stack Development Internship

A collection of full-stack web development projects completed as part of the CodeAlpha Internship.

## Projects

### CodeAlpha Ecommerce
Simple full-stack e-commerce application.

### CodeAlpha SocialMedia
Full-stack social media platform.

## Technology Stack

The projects use modern full-stack web technologies:
- **Frontend**: HTML5, Vanilla JavaScript (ES6+), Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: SQLite (WAL mode, foreign key enforcement)
- **Authentication**: JWT (JSON Web Tokens) & bcryptjs
